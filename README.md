# App Drivers - Presupuesto TI

Aplicación de escritorio desarrollada en Python para automatización y procesamiento de archivos Excel relacionados con presupuesto y drivers.

## Tecnologías

- Python 3.12
- CustomTkinter
- pandas
- openpyxl
- RapidFuzz
- XlsxWriter
- PyInstaller

## Instalación

```powershell
pip install -r requirements.txt
```
